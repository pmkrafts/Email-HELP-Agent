# Password reset link not arriving

1. Confirm the email address on the account is spelled correctly.
2. Check spam/junk and any filtering rules.
3. Request a new link - links expire after 30 minutes.
4. If it still fails, support verifies identity (registered email + last order number)
   and triggers a manual reset from the admin console.

Support agents cannot see or set passwords.
